## Foliant 0.1.0

Erste nutzbare Version.

### Enthalten
- Sprachen wählen, Richtung Fremd↔Deutsch
- Karteikarten mit SRS
- Schreibweise lernen durch Tippen (live Diff, Hinweise, fast-korrekt)
- Seite abfotografieren / Text einfügen, Review vor dem Speichern
- On-device OCR, optional KI über Base URL + Key + Modell
- Google Gemini nativ über generativelanguage.googleapis.com/v1beta inkl. Preset
- Material 3 Expressive (Dynamic Color, Springs, Shape-Morph)
